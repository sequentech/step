# ReviewChangesTable

A generic before/after review table used to confirm a set of pending field
changes before committing them. It renders only the rows passed in -
typically a diff of changed fields - showing the current value struck
through next to the new value. The component is purely presentational:
callers own translation, diffing, and deciding when to show it, which makes
it reusable across any review-before-commit flow in the admin portal.
