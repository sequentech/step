# Every property name in the dbt Charts YAML schema, and what the monitoring
# policy does with it. A key not listed here is refused, so a dbt Charts
# upgrade that adds one cannot reach a widget until someone decides what it is.
#
# Taken from the schema dbt-charts 0.8.0 bundles (YAML schema 0.7.0). The
# renderer's tests check this list against the installed package, and the
# policy's tests check it against the policy.
#
# Rules:
#   allow       any value; strings are still checked for templates, markup
#               and URLs
#   forbid      refused anywhere: brings in data, a destination, markup, an
#               expression, or configures a connection
#   chart_type  a chart type; types showing typed-in content are refused
#   flag        true, false or `auto`; never an expression or a probe
#   geo         a map geometry bundled with the renderer
#   layout      only where the layout places charts
#   names       a mapping keyed by column names or data values; each value is
#               checked as dbt Charts again
#   query       the name of one of the widget's governed queries
#   source      a map geometry under `basemap`, a result column in a
#               support table; refused anywhere else
#   text        style blocks and sizes; as a string only the footer and
#               empty-chart overlay, never markdown content
