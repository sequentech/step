Administre las opciones de idioma del inquilino en el portal de administración.

- Use los botones de opción para seleccionar los idiomas disponibles.
- Establezca el idioma predeterminado seleccionando **Por defecto** junto al idioma correspondiente.
- **Política de detección de idioma**:
  - **Detectar desde el navegador**: el navegador determina el idioma predeterminado.
  - **Forzar predeterminado**: el idioma predeterminado es el que se ha seleccionado como **Por defecto**.
