# Monitoreo

El proceso electoral no tiene una pestaña **Monitoreo** en esta versión del portal de administración. Las versiones anteriores sí la tenían. Si un documento o un compañero le indica que la abra, use las pestañas de la tabla siguiente.

| Para ver | Abra esta pestaña del proceso electoral | Referencia |
| --- | --- | --- |
| El número de electores, de elecciones y de áreas, los emails y los mensajes SMS enviados, los votos a lo largo del tiempo y los votantes por canal. | **Panel de Control** | [Panel de Control](01-election_management_election-event_dashboard.md) |
| El registro de las acciones realizadas en el proceso electoral. | **Registros** | [Registros](11-election_management_election-event_logs.md) |
| Las tareas en segundo plano, por ejemplo importaciones y exportaciones, y su estado. | **Tareas** | [Tareas](10-election_management_election-event_tasks.md) |
| Las solicitudes de inscripción de los votantes y su estado. | **Aprobaciones** | [Aprobaciones](14-election_management_election-event_approvals.md) |

Para ver las cifras de una elección, abra la pestaña **Panel de Control** de esa elección. Consulte [Panel de Control de la elección](../03-election/01-election_management_election_dashboard.md).

:::note
Solo ve una pestaña si su rol lo permite. Si no ve la pestaña **Panel de Control**, pida al administrador del inquilino el permiso para ver el panel de control.
:::
