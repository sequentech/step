Para confirmar cualquier cambio en un proceso electoral, debe publicarlo desde esta pestaña. Además, aquí puede iniciar, pausar y detener procesos electorales.

Todas las publicaciones y sus cambios se pueden consultar en la tabla con el icono de "ojo".

### Opciones de la tabla {#table-options}

- **Columnas**: Active o desactive columnas concretas para mostrarlas.
- **Añadir filtro**: Cree filtros de texto para la tabla por columna.

### Acciones {#actions}

**Cualquier acción realizada en esta pestaña afectará a todas las elecciones asociadas al proceso electoral.**

- **Start Election**: Inicia el proceso electoral.
- **Pause**: Detiene temporalmente el proceso electoral.
- **Stop Election**: Finaliza el proceso electoral.
- **Publicar Cambios**: Aplica cualquier cambio en este proceso electoral.  

---

## Publicar cambios / Vista previa {#publish-changes--preview}

Los cambios de configuración en el portal de administración no se aplican hasta que se publican. Para publicar los cambios, seleccione **Publicar Cambios** en la pestaña **Publicar**.

### Pasos para publicar los cambios {#steps-to-publish-changes}

1. Seleccione **Publicar Cambios**.
2. Escriba su contraseña (las operaciones sensibles requieren contraseña).
3. Revise los cambios.
4. (Opcional) Seleccione **Vista previa** para abrir los cambios del portal de votación en una pestaña aparte (por área).
5. Seleccione **Publicar Cambios** de nuevo para aplicar los cambios.

### Acciones adicionales {#additional-actions}

- **Regenerar**: Regenera los archivos de diferencias.
- **Exportar**: Exporta los archivos de diferencias.
