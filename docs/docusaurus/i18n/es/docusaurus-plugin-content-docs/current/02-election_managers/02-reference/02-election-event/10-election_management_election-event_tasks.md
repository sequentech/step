Supervise la ejecución de las tareas anteriores y consulte información detallada sobre las acciones del sistema. Esta función ofrece información sobre el progreso de las tareas, el comportamiento del sistema y el historial de operaciones, lo que garantiza la transparencia y la trazabilidad.

### Ver una tarea {#view-a-task}

- Seleccione el **icono de ojo** en la columna **Acciones**.
- Consulte la información detallada de esta tarea concreta.
- Seleccione **Atrás** para volver a la tabla.
