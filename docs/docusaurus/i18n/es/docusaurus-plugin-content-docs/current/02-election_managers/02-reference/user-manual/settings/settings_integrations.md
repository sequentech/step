## Descripción general {#overview}

Integraciones con software de terceros. Claves de API, configuraciones, etc.


## Google Meet {#google-meet}

Credenciales relacionadas con el botón de acción **Google Meet** de la pestaña **Datos** del proceso electoral.

### Clave de Cuenta de Servicio de Google Calendar. {#google-calendar-service-account-key}
Pegue la clave completa de la cuenta de servicio en el campo de entrada.
Para generar esa clave puede consultar la [documentación de la API de Google](https://developers.google.com/workspace/guides/create-credentials#service-account) o contactar con el administrador del sistema para obtener ayuda.

### Correo de Autenticación de Google Calendar. {#google-calendar-authentication-email}
Correo electrónico que se usa para la autenticación. Debe estar en el mismo espacio de trabajo que la clave de la cuenta de servicio.
**Nota:** este correo aparecerá como organizador de la reunión.
