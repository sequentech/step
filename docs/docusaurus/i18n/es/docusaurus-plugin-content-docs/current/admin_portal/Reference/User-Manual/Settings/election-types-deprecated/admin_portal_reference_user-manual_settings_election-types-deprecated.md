La pestaña **TIPOS DE ELECCIÓN** guarda una lista de tipos de elección del inquilino. En la
versión 9.0 ninguna otra pantalla usa esta lista: las elecciones no tienen tipo de elección. No
necesita esta pestaña para preparar una elección.

## Abrir la pestaña {#open-the-tab}

1. En el menú de la izquierda, haga clic en **Configuración**.
2. Haga clic en la pestaña **TIPOS DE ELECCIÓN**.

## Elementos de la pantalla {#screen-elements}

| Elemento | Uso |
| --- | --- |
| **Crear un Tipo de Elección** | Abre el formulario **Crear Tipo de Elección**, con el campo **Name** (nombre). |
| **Añadir filtro** | Filtra la lista por **Name**. |
| Iconos de editar y de borrar | Cambian o borran un tipo de elección. |

Cuando la lista está vacía, la pestaña muestra "No hay Tipos de Elección aún.".
