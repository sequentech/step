La pestaña **Aprobaciones** de una elección lista las solicitudes de inscripción de esta elección.
Úsela cuando distintas personas revisan las solicitudes de distintas elecciones.

## Abrir la pestaña {#open-the-tab}

1. En el menú de la izquierda, abra el proceso electoral.
2. Haga clic en la elección.
3. Haga clic en la pestaña **Aprobaciones**.

La pestaña se muestra con el permiso **Ver Aprobaciones de la Elección**. Está oculta cuando el
proceso electoral está confinado.

## Elementos de la pantalla {#screen-elements}

La pestaña tiene los mismos filtros, columnas y acciones que la pestaña **Aprobaciones** del
proceso electoral. Consulte [Proceso electoral: Aprobaciones](../../Election-Event/Approvals/election_management_election-event_approvals.md).
Si la elección tiene una etiqueta de permiso, la lista solo muestra las solicitudes con esa
etiqueta. Si la elección no tiene etiqueta de permiso, la lista muestra todas las solicitudes del
proceso electoral.

## Si hay un problema {#if-there-is-a-problem}

| Problema | Acción |
| --- | --- |
| La lista está vacía, pero el proceso electoral tiene solicitudes. | Las solicitudes no tienen la etiqueta de permiso de esta elección. Use la pestaña **Aprobaciones** del proceso electoral. |
| "No tienes permiso para acceder a esta elección." | La elección tiene una etiqueta de permiso que su cuenta no tiene. Consulte [Etiquetas de permiso](../../../../../Tutorials/admin_portal_tutorials_permission-labels.md). |
