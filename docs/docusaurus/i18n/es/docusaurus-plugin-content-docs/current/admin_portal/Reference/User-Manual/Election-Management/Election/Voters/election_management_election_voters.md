La pestaña **Votantes** de una elección muestra los votantes que pueden votar en esta elección. Un
votante puede votar en una elección cuando el área del votante contiene una o más preguntas de esa
elección.

## Abrir la pestaña {#open-the-tab}

1. En el menú de la izquierda, abra el proceso electoral.
2. Haga clic en la elección.
3. Haga clic en la pestaña **Votantes**.

La pestaña se muestra con el permiso **Ver Votantes de la Elección**.

## Elementos de la pantalla {#screen-elements}

La pestaña tiene la misma barra de herramientas, columnas, acciones y formularios que la pestaña
**Votantes** del proceso electoral. Consulte
[Proceso electoral: Votantes](../../Election-Event/Voters/election_management_election-event_voters.md).

Se aplican estas diferencias:

| Elemento | Diferencia |
| --- | --- |
| Lista | Solo los votantes cuya área tiene una pregunta de esta elección. |
| Columna **Voted** (ha votado) | Si el votante ha emitido un voto en esta elección. |
| **Exportar** | Exporta solo los votantes de esta elección. |

Para añadir votantes, use la pestaña **Votantes** del proceso electoral. Un votante se muestra aquí
cuando usted le asigna un área con una pregunta de esta elección.

## Si hay un problema {#if-there-is-a-problem}

| Problema | Acción |
| --- | --- |
| Un votante no está en la lista. | Compruebe el área del votante. Después compruebe que el área tiene una pregunta de esta elección en la pestaña **Áreas**. |
| "No tienes permiso para acceder a esta elección." | La elección tiene una etiqueta de permiso que su cuenta no tiene. Consulte [Etiquetas de permiso](../../../../../Tutorials/admin_portal_tutorials_permission-labels.md). |
