La parte de referencia del manual tiene una página para cada pantalla del portal de
administración, versión 9.0. Cada página indica para qué sirve la pantalla, cómo abrirla, los
permisos, los campos y los botones, y qué hacer si hay un problema. Para el orden del trabajo,
use los procedimientos. Consulte [Gestión electoral](../../election_management.md).

## Pantallas {#screens}

| Elemento del menú | Contenido | Página de referencia |
| --- | --- | --- |
| - | Las partes de la pantalla y el menú. | [Navegación básica](../basic_navigation.md) |
| **Procesos Electorales** | Los procesos electorales, las elecciones, las preguntas y los candidatos, con todas sus pestañas. | [Gestión electoral](Election-Management/election_management_admin_portal_reference_user-manual_election-management.md) |
| **Usuarios y Roles** | Las cuentas de los administradores y de los fideicomisarios, y los roles. | [Usuarios y roles](Users-and-Roles/admin_portal_reference_user-manual_users-and-roles.md) |
| **Configuración** | La configuración del inquilino. | [Configuración](Settings/admin_portal_reference_user-manual_settings.md) |
| **Plantillas** | Las plantillas de los mensajes y de los documentos. | [Plantillas](Templates/admin_portal_reference_user-manual_templates.md) |
| **Ayuda** | Los enlaces de ayuda del inquilino. Se muestra solo si el inquilino tiene enlaces de ayuda. | [Personalización de apariencia](Settings/look--feel/admin_portal_reference_user-manual_settings_look--feel.md) |

Si una pestaña o un botón de una página de referencia no está en su pantalla, su rol no tiene
el permiso correspondiente. Pregunte a su administrador del inquilino.
