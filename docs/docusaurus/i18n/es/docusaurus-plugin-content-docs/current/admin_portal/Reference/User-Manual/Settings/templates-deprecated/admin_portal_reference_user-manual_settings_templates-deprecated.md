La pestaña **PLANTILLAS** de **Configuración** muestra si el inquilino puede enviar mensajes por
correo electrónico y por mensaje de texto. No puede cambiar los valores en esta pestaña. Para
crear las plantillas de los mensajes y de los documentos, use **Plantillas** en el menú de la
izquierda. Consulte [Plantillas](../../Templates/admin_portal_reference_user-manual_templates.md).

## Abrir la pestaña {#open-the-tab}

1. En el menú de la izquierda, haga clic en **Configuración**.
2. Haga clic en la pestaña **PLANTILLAS**.

## Campos {#fields}

| Campo | Uso |
| --- | --- |
| **Mails** | Muestra si el inquilino puede enviar correos electrónicos. Solo lectura. |
| **SMS** | Muestra si el inquilino puede enviar mensajes de texto. Solo lectura. |

Para cambiar estos valores, contacte con el soporte de Sequent.
