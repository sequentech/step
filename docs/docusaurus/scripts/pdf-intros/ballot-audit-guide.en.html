About This Guide

This guide contains two procedures of the Ballot Audit Manual: Prepare the Backups and Run the Audit. One docker run command restores the backups and audits all areas and contests of the tally.

Requirements

  • A computer with Docker.
  • The audit image. To get or build it, see Set Up the Audit Workstation in the online manual.
  • The backups and their digests from the system operator.
  • The tally ID, the public key hash and the electoral log system public key from the election authority.

More information

For all other information, use the Ballot Audit Manual online: {{manual}}

For the evidence, checks and conclusions of the verification process, read What the Ballot Audit Verifies.
