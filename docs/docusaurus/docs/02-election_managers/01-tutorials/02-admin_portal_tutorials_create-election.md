This tutorial guides you through the process of creating a new electoral event, setting up specific elections, and adding contests and candidates within the Sequent Admin Portal.

## Step 1: Initiate Election Event Creation

There are three ways to start creating a new electoral event from the sidebar:

1.  **Election Events Menu:** Select the `Election Events` menu and click `Create Electoral Event`.
2.  **Election List:** Click the **three-dot icon** next to an existing election and select `Create an Election Event`.
3.  **Direct Link:** Click the `+ Create an Election Event` button directly in the sidebar.

## Step 2: Configure Event Details


After initiating the process, you must provide the basic identity for the event.

1.  Enter the **Name** of the election event.
2.  Provide a **Description** (optional).
3.  Select `Save`.

:::info
**Post-Creation Options:** Once saved, the system will unlock several tabs including **Monitoring**, **Data**, **Localization**, and **Voters** to further refine your event.
:::

## Step 3: Set Event Data and Preferences


In the **Data** tab, you can manage how the event appears and behaves across different regions.

1.  **Localization:** Define names and aliases in different languages (e.g., English, Spanish).
2.  **Ballot Design:** Customize the visual presentation of the ballot.
3.  **Advanced Configurations:** Set specific policies such as the **Countdown** timer or **Encryption Policy**.

## Step 4: Create a Specific Election

An Election Event can contain one or more specific elections.

1.  In the sidebar under your new event, select `+ Create an Election`.
2.  Enter the **Name** and **Description**.
3.  Select `Save`.

:::tip
**Granular Control:** Each election within an event can have its own unique ballot design, voting channels, and authentication levels.
:::

## Step 5: Add Contests and Candidates


Define what voters are actually voting for by adding contests (questions) and their respective options.

1.  **Create a Contest:** Select `+ Create a Contest` under the specific election. Enter the question or title and click `Save`.
2.  **Add Candidates:** Under the newly created contest, select `+ Create a Candidate`.
3.  Enter the candidate's name and details, then select `Save`.
