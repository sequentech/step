The **ELECTION TYPES** tab is in **Settings**. It is **not in use**. You do not have to set it.

The tab keeps a list of election type names for the tenant. No other part of the admin portal
or the voting portal reads this list. An election type that you add here does not change an
election event, an election or a ballot.

## How to open it

1. In the menu on the left, click **Settings**.
2. Click the **ELECTION TYPES** tab.

## What the tab shows

| Item | Meaning |
| --- | --- |
| **No Election Types yet.** | The list is empty. This is the usual state. |
| **Create Election Type** | Opens a form with one field, the name of the election type. |
| Edit and delete icons | Change or remove a name in the list. |

## What to use instead

To configure an election, use the screens of the election event and of the election:

- The settings of the election event are on its **Data** tab. See
  [Election event data](../../02-election-event/03-election_management_election-event_data.md).
- The procedure that creates an election event is
  [Create the Election Event](../../../03-procedures/02-event.md).
