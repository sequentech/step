# Monitoring

The election event has no **Monitoring** tab in this version of the admin portal. Earlier
versions had this tab. If a document or a colleague tells you to open it, use the tabs in the
table below.

| To see | Open this tab of the election event | Reference |
| --- | --- | --- |
| The number of eligible voters, elections and areas, the emails and SMS messages sent, the votes over time and the voters by channel. | **Dashboard** | [Dashboard](01-election_management_election-event_dashboard.md) |
| The record of the actions in the election event. | **Logs** | [Logs](11-election_management_election-event_logs.md) |
| The background tasks, for example imports and exports, and their status. | **Tasks** | [Tasks](10-election_management_election-event_tasks.md) |
| The enrollment applications of voters and their status. | **Approvals** | [Approvals](14-election_management_election-event_approvals.md) |

For the numbers of one election, open the **Dashboard** tab of that election. See
[Election dashboard](../03-election/01-election_management_election_dashboard.md).

:::note
You see a tab only if your role permits it. If you do not see the **Dashboard** tab, ask your
tenant administrator for permission to see the dashboard.
:::
