# Monitoring

The election has no **Monitoring** tab in this version of the admin portal. Earlier versions had
this tab. The election has these tabs: **Dashboard**, **Data**, **Voters**, **Publish**,
**Approvals** and **Tally Sheets**. You see only the tabs that your role permits.

| To see | Open this tab | Reference |
| --- | --- | --- |
| The eligible voters, the actual voters, the areas, the emails and SMS messages sent, the votes over time and the voters by channel of this election. | **Dashboard** of the election | [Election dashboard](01-election_management_election_dashboard.md) |
| The same numbers for all the elections of the election event. | **Dashboard** of the election event | [Election event dashboard](../02-election-event/01-election_management_election-event_dashboard.md) |
| The record of the actions in the election event. | **Logs** of the election event | [Logs](../02-election-event/11-election_management_election-event_logs.md) |
| The enrollment applications of voters for this election. | **Approvals** of the election | [Approvals](06-election_management_election_approvals.md) |
