The **Data** tab of a candidate holds the texts, the type and the image of one candidate. A
candidate is one option that a voter can select in a contest.

## Open the tab

1. In the menu on the left, open the election event, the election and the contest.
2. Click the candidate.
3. Click the **Data** tab.

To save changes, your role needs the **Edit Candidate** permission.

To create a candidate, click the arrow next to the contest in the menu to show its candidates, then click
**Create a Candidate**. Type the **Name** and click **Save**.

## Sections

| Section | Fields | Use |
| --- | --- | --- |
| **General** | One tab for each language with **Name**, **Alias** and **Description**, and **Disabled** | The texts of the candidate. **Disabled** marks the candidate as disabled. |
| **Type** | **Type**, **Subtype**, **Invalid Vote**, **Blank Vote**, **Category List**, **Write-in**, **Invalid Vote Position** | The kind of option. Use these fields for lists, write-in options and options that mean an invalid or blank vote. |
| **Image** | An image file | The photo or the logo of the candidate. |

**Invalid Vote Position** has **None (Default)**, **Top** and **Bottom**. It sets where the
invalid vote option shows on the ballot.

## If there is a problem

| Problem | Action |
| --- | --- |
| "Error creating candidate" | Check the **Name**, then save again. |
| A change does not show in the voting portal. | Make and publish a new publication. See [Publish and Manage the Voting Period](../../../../../procedures/05-publish.md). |
| The **Save** button is not there. | Your role does not have the **Edit Candidate** permission. |
