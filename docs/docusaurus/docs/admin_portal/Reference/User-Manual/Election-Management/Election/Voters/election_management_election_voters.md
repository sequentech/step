The **Voters** tab of an election shows the voters who can vote in this election. A voter can
vote in an election when the area of the voter contains one or more contests of that election.

## Open the tab

1. In the menu on the left, open the election event.
2. Click the election.
3. Click the **Voters** tab.

The tab shows with the **View Election Voters** permission.

## Screen elements

The tab has the same toolbar, columns, actions and forms as the **Voters** tab of the election
event. See [Election event: Voters](../../Election-Event/Voters/election_management_election-event_voters.md).

These differences apply:

| Element | Difference |
| --- | --- |
| List | Only the voters whose area has a contest of this election. |
| **Voted** column | If the voter has cast a vote in this election. |
| **Export** | Exports only the voters of this election. |

To add voters, use the **Voters** tab of the election event. A voter shows here when you give
the voter an area with a contest of this election.

## If there is a problem

| Problem | Action |
| --- | --- |
| A voter is not in the list. | Check the area of the voter. Then check that the area has a contest of this election on the **Areas** tab. |
| "You don't have permission to access this election." | The election has a permission label that your account does not have. See [Permission Labels](../../../../../Tutorials/admin_portal_tutorials_permission-labels.md). |
