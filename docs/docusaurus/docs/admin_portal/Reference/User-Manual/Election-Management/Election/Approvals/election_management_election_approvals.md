The **Approvals** tab of an election lists the enrollment applications for this election.
Use it when different persons review the applications of different elections.

## Open the tab

1. In the menu on the left, open the election event.
2. Click the election.
3. Click the **Approvals** tab.

The tab shows with the **View Election Approvals** permission. It is hidden when the election
event is locked down.

## Screen elements

The tab has the same filters, columns and actions as the **Approvals** tab of the election
event. See [Election event: Approvals](../../Election-Event/Approvals/election_management_election-event_approvals.md).
If the election has a permission label, the list shows only the applications with that label.
If the election has no permission label, the list shows all the applications of the election
event.

## If there is a problem

| Problem | Action |
| --- | --- |
| The list is empty, but the election event has applications. | The applications do not have the permission label of this election. Use the **Approvals** tab of the election event. |
| "You don't have permission to access this election." | The election has a permission label that your account does not have. See [Permission Labels](../../../../../Tutorials/admin_portal_tutorials_permission-labels.md). |
