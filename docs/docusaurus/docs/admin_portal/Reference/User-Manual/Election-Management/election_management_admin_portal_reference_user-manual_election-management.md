An election event has four levels: the election event, its elections, their contests and the
candidates. In the menu on the left, they show as a tree under **Election Events**. Click an
item to open it. Each item has tabs. This page lists the reference page of each tab.

## Actions in the menu

Click the three dots next to an item in the menu to see its actions:

| Item | Actions |
| --- | --- |
| Election event | **Create an Election**, **Import an Election Event**, **Archive this Election Event** or **Unarchive this Election Event**, **Remove this Election Event** |
| Election | **Create a Contest**, **Remove this Election** |
| Contest | **Create a Candidate**, **Remove this Contest** |
| Candidate | **Remove this Candidate** |

Each action shows only if your role has its permission. The admin portal asks for a confirmation
before an archive or a removal.
