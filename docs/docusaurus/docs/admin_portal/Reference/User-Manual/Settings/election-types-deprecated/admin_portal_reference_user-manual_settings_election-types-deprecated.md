The **ELECTION TYPES** tab keeps a list of election types for the tenant. In version 9.0 no
other screen uses this list: elections do not have an election type. You do not need this tab
to prepare an election.

## Open the tab

1. In the menu on the left, click **Settings**.
2. Click the **ELECTION TYPES** tab.

## Screen elements

| Element | Use |
| --- | --- |
| **Create Election Type** | Opens the form **Create Election Type**, with the field **Name**. |
| **Add filter** | Filters the list by **Name**. |
| Edit and delete icons | Change or delete an election type. |

When the list is empty, the tab shows "No Election Types yet.".
