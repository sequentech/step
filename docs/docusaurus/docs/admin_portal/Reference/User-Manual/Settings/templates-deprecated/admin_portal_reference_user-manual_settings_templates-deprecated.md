The **TEMPLATES** tab of **Settings** shows if the tenant can send messages by email and by
text message. You cannot change the values on this tab. To make the message and document
templates, use **Templates** in the menu on the left. See
[Templates](../../Templates/admin_portal_reference_user-manual_templates.md).

## Open the tab

1. In the menu on the left, click **Settings**.
2. Click the **TEMPLATES** tab.

## Fields

| Field | Use |
| --- | --- |
| **Mails** | Shows if the tenant can send emails. Read only. |
| **SMS** | Shows if the tenant can send text messages. Read only. |

To change these values, contact Sequent support.
