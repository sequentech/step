The **Countries** tab blocks voting and enrollment from the countries that you select. The
title of the tab content is **Country Blocking**.

## Open the tab

1. In the menu on the left, click **Settings**.
2. Click the **Countries** tab.

## Fields

| Field | Use |
| --- | --- |
| **Countries** under "Choose below the countries you want to block voting from." | The countries from which voters cannot vote. |
| **Countries** under "Choose below the countries you want to block enrollment from." | The countries from which voters cannot enroll. |
| **Save** | Saves the lists. |

The permission list of a role names this function **Edit Country Blocking Rules in
Cloudflare**.

## Block countries

1. In the first **Countries** field, select the countries to block for voting.
2. In the second **Countries** field, select the countries to block for enrollment.
3. Click **Save**.

## If there is a problem

| Problem | Action |
| --- | --- |
| "Error saving the country list" | Try again. If the error stays, contact Sequent support. |
