The reference part of the manual has one page for each screen of the admin portal, version 9.0.
Each page tells what the screen is for, how to open it, the permissions, the fields and buttons,
and what to do if there is a problem. For the order of the work, use the procedures. See
[Election Management](../../election_management.md).

## Screens

| Menu item | Content | Reference page |
| --- | --- | --- |
| - | The parts of the screen and the menu. | [Basic Navigation](../basic_navigation.md) |
| **Election Events** | The election events, elections, contests and candidates, with all their tabs. | [Election Management](Election-Management/election_management_admin_portal_reference_user-manual_election-management.md) |
| **Users and Roles** | The accounts of the administrators and trustees, and the roles. | [Users and Roles](Users-and-Roles/admin_portal_reference_user-manual_users-and-roles.md) |
| **Settings** | The configuration of the tenant. | [Settings](Settings/admin_portal_reference_user-manual_settings.md) |
| **Templates** | The templates of the messages and documents. | [Templates](Templates/admin_portal_reference_user-manual_templates.md) |
| **Help** | The help links of the tenant. It shows only if the tenant has help links. | [Look & Feel](Settings/look--feel/admin_portal_reference_user-manual_settings_look--feel.md) |

If a tab or a button of a reference page is not on your screen, your role does not have its
permission. Ask your tenant administrator.
