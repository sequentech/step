From `packages/`, using the repository's pinned Rust toolchain:

```sh
cargo test --locked -p b3 --features client,server,sqlcopy --tests
```

Install PostgreSQL and `libpq-dev`, or set `PG_BIN` to a directory containing
`initdb` and `pg_ctl`. Run as an ordinary user. The database fixture owns a
temporary cluster with a private Unix socket and removes it on success or panic.
It never reads deployment credentials or connects to an existing database.

Tests check independent Borsh wire layouts, malformed hash lists, controlled
writer errors, configuration membership, signature rejection and bootstrap
artifact consistency. The database fixture checks board isolation, exclusive
pagination, rollback and distinct creation/statement timestamps. Message mapping
also rejects integer overflow.

From the repository root:

```sh
python3 scripts/coverage/run.py b3 --baseline
```

The profile enables client, server and SQL-copy compilation and counts inline
tests and generated serialization. CI compares lines, functions and LLVM regions
separately against the actual PR base; regions are not branches. The legacy tests
requiring an external deployment remain ignored. Live gRPC server behavior,
SQL-copy batching and complete protocol workflows need additional execution;
enabling their features alone does not establish coverage of those paths.
