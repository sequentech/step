Appendix: Run Each Step Separately

Run the Audit runs all commands of the audit with audit-tally. This appendix runs the same commands one at a time, for one scope: one election, one area and one contest of the tally.

Use this appendix to do these tasks:

  • Build the tools and restore the copies without the audit image.
  • Repeat a step that did not pass, after you correct its cause.
  • Examine the files of one step.
  • Look up the receipt of a voter. See Audit the Bundle.

Do the procedures in this order. Check the Cast-Vote History is optional when you do only one scope.

StepProcedureResult
Without the Audit ImageOnly if you do not use the audit image: the tools and the copies.
1Get the Scope and the PinsA pinned scope.json file.
2Export the EvidenceThe evidence files and their digests.
3Prepare the Audit BundleAn audit bundle.
4Audit the BundleAn audit report.
5Verify the Bulletin BoardA Braid result for each batch.
6Check the Cast-Vote HistoryA history report.

Use the procedures with the audit image​

The procedures give the commands without the audit image. With the image, open a shell in a container that has the copies, and type the commands there:

docker run --rm -it --network none \
  -v ~/audit/backups:/backups:ro -v ~/audit/output:/output "$AUDIT_IMAGE" shell

The output directory must be empty. The shell starts in /output, which is ~/audit/output. The copies stop when you leave the shell. Change the commands as this table shows:

cd ~/auditThe shell is in /output. Write scope.json there.

note

audit-tally writes the files of each scope in output/scopes/<NNN>/. To examine one step of a run, use the command line of the step in output/audit-record.json. To repeat it, use a new, empty output directory.

After the last procedure, do Report and Remove the Copies.
