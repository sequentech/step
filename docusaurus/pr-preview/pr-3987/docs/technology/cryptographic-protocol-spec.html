Reference Overview

The election cryptographic backend is the supplied packages/wbraid workspace. Its braid crate runs distributed key generation, verifiable mixing and threshold decryption; its vsc crate exposes the cryptography library used for the cryptographic operations. Its b4 crate supplies the native b4v6 board service.

Trustee custody​

Trustees register separate signing and share encryption public keys. Manual ceremonies exchange public custody requests and signed public custody proofs. Automatic ceremonies skip manual custody confirmation while retaining the same cryptographic protocol. Both require the selected trustees' runners to participate. The platform receives neither trustee identity files nor election shares, and threshold decryption does not reconstruct the private key.

See native and browser trustee configuration for setup, backups and recovery.

Verification evidence​

Single-contest and combined-contest audit decoding verifies the Naor–Yung proof against the ballot style's public key and configuration, then checks that the revealed plaintext and randomness reconstruct the encrypted values. A valid tracker or voter signature alone does not validate an audit opening. Invalid openings fail before any selections are returned.

Public transcript verification requires an independently trusted configuration hash and tally identifier. A board's own self-signed configuration is insufficient as its trust anchor. Incomplete evidence does not pass verification.

Cryptographic transcript verification checks the published tally input. Checking how that input was selected from the sealed ballot box, including revotes and weights, also requires ballot-box evidence and the platform's batching and counting checks. See public verification and ballot-box seal verification.

The detailed supplied protocol and canonical serialization specification live in packages/wbraid/PROTOCOL.md and packages/wbraid/SERIALIZATION.md. General TLS, voter-field encryption, certificate signatures and document protection remain separate application facilities.
