API endpoint for inserting votes. POST coming from the frontend->Hasura->Harvest->Here.

It tries to insert the vote into the database and returns the Json result in case of success or logs the information of the error (coming from a synchronous windmill library function, try_insert_cast_vote) before returning the error.
