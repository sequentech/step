Elections, Contests and Candidates in the Election Event File

This page gives the format of the elections, contests and candidates arrays of the election event JSON file. The other parts of the file are on Election Event File. Use this page to read an export or to check a file before you import it.

NOTE: election event file

Make the election event file with Export on the election event. Change the file by hand only if you must, and only the fields on this page. Import the changed file into a test election event first.

How the objects are linked​

The file has three flat arrays. The objects refer to each other through IDs:

election_event.id
 └─ elections[].election_event_id      (one election event, many elections)
     elections[].id
      └─ contests[].election_id        (one election, many contests)
          contests[].id
           └─ candidates[].contest_id  (one contest, many candidates)
  • Each election, contest and candidate has tenant_id and election_event_id. Use the values of tenant_id and election_event.id at the top of the file.
  • contests[].election_id must be the id of an election in elections.
  • candidates[].contest_id must be the id of a contest in contests.
  • The links between areas and contests are in area_contests. See Election Event File.

IDs​

  • Each id and each reference to an id is a UUID, for example 3f2b8c1e-5d6a-4b7c-9e8f-0a1b2c3d4e5f. The import refuses other values, for example election-1.
  • The import gives new IDs. It replaces each UUID in the file with a new UUID. The same old UUID always gets the same new UUID, so the links stay correct. This also applies to UUIDs inside presentation, annotations and text fields.
  • The import puts the election event in the tenant that you are signed in to. It replaces the tenant_id of the file with the ID of that tenant.
CAUTION: contest ID of a candidate

Make sure that candidates[].contest_id is the id of a contest in the file. If it is not, the import does not stop: it adds the candidate without a contest, and the candidate is not on any ballot.

Values that the import changes​

For each election, the import:

  • Sets the voting status of the online, kiosk and telephone channels to NOT_STARTED.
  • Clears the start, pause and stop dates of these channels.
  • Sets statistics to zero and initialization_report_generated to false.

The import keeps all other fields as they are in the file. It does not change contests or candidates.

Common types​

TypeFormat
UUIDA UUID as text. The import replaces it with a new version 4 UUID.
Date and timeISO 8601 text with a time zone, for example 2026-05-01T08:00:00Z.
i18n mapAn object. Each key is a language code (en, es, ...). Each value is an object of text fields, for example {"en": {"name": "Election 1"}, "es": {"name": "Elección 1"}}.
AnnotationsAn object. Each value must be text. To store an object, store it as JSON text.
JSONAny JSON value.
CAUTION: annotations of contests, candidates and elections

Make sure that each value in annotations of a contest, a candidate or an election is text. If a value is a number, an object or a list, the publication of the ballot fails.

Elections​

Each object in elections is one election.

FieldTypeRequiredDefaultMeaning
idUUIDYes-The ID of the election.
tenant_idUUIDYes-The tenant.
election_event_idUUIDYes-The election event.
created_atDate and timeNo-Not imported. The import sets the time of the import.
last_updated_atDate and timeNo-Not imported. The import sets the time of the import.
labelsJSONNonullInternal. Keep the value from the export.
annotationsAnnotationsNonullExtra data. The admin portal stores the telephone voting prompts here, in the key ivr:i18n (JSON text with a prompt for each language).
descriptionTextNonullThe description. The admin portal copies it from presentation.i18n.en.description.
presentationObjectNonullThe settings of the election in the voting portal: names, languages, ballot design and policies. See Election Presentation File. The import refuses a value that is not correct.
statusObjectNonullThe status of the election. See Election status.
emlTextNonullInternal. Keep the value from the export.
external_idTextNonullAn ID that you give to the election, for example the ID in another system. The admin portal shows it as External ID.
num_allowed_revotesIntegerNonull (= 1)The number of times that a voter can cast a ballot in the election. 0 means no limit. If the field is empty, the limit is 1.
is_consolidated_ballot_encodingBooleanNonullInternal. Keep the value from the export.
spoil_ballot_optionBooleanNonullInternal. Keep the value from the export.
is_kioskBooleanNonullInternal. Keep the value from the export.
voting_channelsObjectNonullThe voting channels of the election. See Voting channels.
image_document_idTextNonullThe ID of the image document of the election. In a .json file without documents, the image is not in the file.
statisticsObjectNo-Reset by the import: {"num_emails_sent": 0, "num_sms_sent": 0}.
receiptsObjectNonullThe receipts that voters get. See Receipts.
permission_labelTextNonullOnly admin portal users with this permission label can see and change the election.
keys_ceremony_idUUIDNonullThe keys ceremony of the election. Use it only if the file also contains this keys ceremony.
initialization_report_generatedBooleanNo-Reset by the import to false.

The election has no name field. The name, the alias and the description in each language are in presentation.i18n.

Election status​

All fields are optional. A missing field gets the default value.

FieldTypeDefaultAllowed values and meaning
is_publishedBooleanfalsetrue if a ballot of the election was published.
voting_statusTextNOT_STARTEDThe status of the online channel: NOT_STARTED, OPEN, PAUSED, CLOSED. The import resets it.
kiosk_voting_statusTextNOT_STARTEDThe same values, for the kiosk channel. The import resets it.
early_voting_statusTextNOT_STARTEDThe same values, for the early voting channel.
telephone_voting_statusTextNOT_STARTEDThe same values, for the telephone channel. The import resets it.
voting_period_datesObjectemptyThe dates of the online channel. The import resets it.
kiosk_voting_period_datesObjectemptyThe dates of the kiosk channel. The import resets it.
early_voting_period_datesObjectemptyThe dates of the early voting channel.
telephone_voting_period_datesObjectemptyThe dates of the telephone channel. The import resets it.
init_reportTextallowedallowed or disallowed. If disallowed, you cannot make the initialization report.
allow_tallyTextallowedallowed, disallowed or requires-voting-period-end. The Allow Tally setting of the election.

Each dates object has these fields, all optional, as date and time: first_started_at, last_started_at, first_paused_at, last_paused_at, first_stopped_at, last_stopped_at.

Voting channels​

FieldTypeMeaning
onlineBooleanVoters can vote in the voting portal.
kioskBooleanVoters can vote at a kiosk.
telephoneBooleanVoters can vote by telephone.
paperBooleanPaper voting.
early_votingBooleanVoters in areas with early voting can vote before the online channel opens.

Receipts​

An object with the keys EMAIL, SMS and DOCUMENT. Each value is an object:

FieldTypeMeaning
allowedBooleanThe voter can get the receipt by this method.
templateText or nullInternal. Keep the value from the export.

Contests​

Each object in contests is one contest of an election.

FieldTypeRequiredDefaultMeaning
idUUIDYes-The ID of the contest.
tenant_idUUIDYes-The tenant.
election_event_idUUIDYes-The election event.
election_idUUIDYes-The election of the contest.
created_at, last_updated_atDate and timeNo-Not imported. The import sets the time of the import.
labelsJSONNonullInternal. Keep the value from the export.
annotationsAnnotationsNonullExtra data. The admin portal stores the telephone voting prompts here, in the key ivr:i18n.
is_acclaimedBooleanNofalsetrue if the contest is decided by acclamation. The voter sees the contest but does not vote in it. See Acclaimed Contests.
is_activeBooleanNonullInternal. Keep the value from the export.
descriptionTextNonullThe description. The admin portal copies it from presentation.i18n.en.description.
presentationObjectNosee Contest presentationThe settings of the contest on the ballot. The import refuses a value that is not correct.
min_votesIntegerNo0The minimum number of selections that the voter must make.
max_votesIntegerNo0The maximum number of selections that the voter can make. Always set it.
winning_candidates_numIntegerNo1The number of winners.
voting_typeTextNonullnon-preferential or preferential. The admin portal sets non-preferential.
counting_algorithmTextYes, to publish-The counting method. See Counting algorithms.
is_encryptedBooleanNofalseInternal. Keep the value from the export.
tally_configurationObjectNonullTally settings. The key tie_breaking_policy sets what the tally does with a tie: random (default) or external-procedure.
conditionsJSONNonullInternal. Keep the value from the export.
image_document_idTextNonullThe ID of the image document of the contest.
external_idTextNonullAn ID that you give to the contest. It goes into the published ballot, and the custom CSS of the voting portal can use it.
CAUTION: counting algorithm of a contest

Set counting_algorithm for each contest. If it is empty or not an allowed value, the publication of the ballot fails.

Counting algorithms​

The import accepts these values of counting_algorithm. Upper case and lower case are both accepted.

ValueIn the admin portal
plurality-at-largeYes
instant-runoffYes
borda-nauru, borda, borda-mas-madrid, pairwise-beta, desborda3, desborda2, desborda, cumulativeNo. The admin portal does not show these values, because the tally does not fully support them.

Contest presentation​

All fields are optional.

FieldTypeDefaultAllowed values and meaning
i18ni18n mapnoneThe text of the contest in each language. Keys: name, alias, description. If alias is set, the voting portal shows it in place of the name.
allow_writeinsBooleanfalsetrue: the voter can type a name in the write-in candidates of the contest.
base32_writeinsBooleantruetrue: write-in text uses a reduced character set (Base32). false: a larger character set.
invalid_vote_policyTextallowedWhat the voting portal does with an invalid ballot. See Contest policies.
under_vote_policyTextallowedWhat the voting portal does if the voter selects fewer than max_votes.
blank_vote_policyTextallowedWhat the voting portal does with a blank vote.
over_vote_policyTextallowed-with-msg-and-alertWhat the voting portal does if the voter selects more than max_votes. The admin portal writes allowed for a new contest.
duplicated_rank_policyTextallowed-warn-and-dialogFor preferential contests: what the voting portal does if the voter gives the same rank twice.
preference_gaps_policyTextallowed-warn-and-dialogFor preferential contests: what the voting portal does if there is a gap in the ranks.
pagination_policyText""A page name. The voting portal shows the contests with the same value on the same page, in ballot order. Empty: all contests without a value share one page.
cumulative_number_of_checkboxesInteger1For the cumulative algorithm: the number of points that the voter can give to one candidate.
shuffle_categoriesBooleanfalsetrue: the voting portal shows the lists (candidate types) in a random order. false: it uses the sort_order in types_presentation.
shuffle_category_listList of textnoneThe lists (candidate types) whose candidates the voting portal shows in a random order.
show_pointsBooleanfalsetrue: the Ballot Verifier shows the points that the counting algorithm gives to each selection on its confirmation screen. false: each selection gets 0 points, so no points are shown.
enable_checkable_listsTextnone (the admin portal writes allow-selecting-candidates-and-lists)What the voter can select when the contest has lists: allow-selecting-candidates-and-lists, allow-selecting-candidates, allow-selecting-lists, disabled.
collapsible_listsTextnone (the admin portal writes disabled)disabled, enabled-expanded (the voter can close a list; lists start open), enabled-collapsed (lists start closed).
candidates_orderTextalphabeticalalphabetical, random, custom. With custom, the order is the sort_order of each candidate.
candidates_selection_policyTextcumulativeradio: a new selection removes the earlier selection. cumulative: selections add up.
candidates_icon_checkbox_policyTextsquare-checkboxsquare-checkbox or round-checkbox.
max_selections_per_typeIntegernoneThe maximum number of selected candidates of the same type.
types_presentationObjectnoneThe display of each candidate type. See Types presentation.
sort_orderIntegernoneThe position of the contest when the election uses the custom contest order.
columnsInteger1The number of columns of candidates on the ballot.

The defaults are the values that the system uses when the field is missing. The admin portal writes most of these fields when you save a contest. If the contest has no presentation at all, the system uses allow_writeins: true and over_vote_policy: allowed.

Contest policies​

FieldAllowed values
invalid_vote_policyallowed, warn, warn-invalid-implicit-and-explicit, not-allowed, allowed-with-exclusive-explicit
under_vote_policyallowed, warn, warn-only-in-review, warn-and-alert
blank_vote_policyallowed, warn, warn-only-in-review, not-allowed
over_vote_policyallowed, allowed-with-msg, allowed-with-msg-and-alert, not-allowed-with-msg-and-alert, not-allowed-with-msg-and-disable
duplicated_rank_policyallowed-warn-and-dialog, not-allowed-warn-and-dialog
preference_gaps_policyallowed-warn-and-dialog, not-allowed-warn-and-dialog

With allowed-with-exclusive-explicit, the explicit invalid option cannot be selected together with candidates. If one contest of the election has over_vote_policy set to allowed, allowed-with-msg or allowed-with-msg-and-alert, or has no value, the ballot of the whole election uses a larger layout that can hold the extra selections.

Types presentation​

An object. Each key is a candidate type. Each value is an object:

FieldTypeMeaning
nameTextThe name of the type.
name_i18nObjectThe name in each language: {"en": "North"}.
sort_orderIntegerThe position of the type.
subtypes_presentationObjectEach key is a candidate subtype. Each value has name, name_i18n and sort_order.

Candidates​

Each object in candidates is one candidate. The explicit blank and explicit invalid options and the write-in fields are also candidates.

FieldTypeRequiredDefaultMeaning
idUUIDYes-The ID of the candidate.
tenant_idUUIDYes-The tenant. The import uses the tenant of the file.
election_event_idUUIDYes-The election event. The import uses the election event of the file.
contest_idUUIDNonullThe contest of the candidate. A candidate without a contest is not on any ballot.
created_at, last_updated_atDate and timeNo-Not imported. The import sets the time of the import.
labelsJSONNonullInternal. Keep the value from the export.
annotationsAnnotationsNonullExtra data. The admin portal stores the telephone voting prompts here, in the key ivr:i18n.
descriptionTextNonullThe description.
typeTextNonullThe list (category) of the candidate, as free text. The voting portal shows candidates with the same type together. types_presentation of the contest uses this value.
presentationObjectNosee Candidate presentationThe settings of the candidate on the ballot. The import refuses a value that is not correct.
is_publicBooleanNonullInternal. Keep the value from the export.
image_document_idTextNonullThe ID of the image document of the candidate.
external_idTextNonullAn ID that you give to the candidate.

Candidate presentation​

All fields are optional.

FieldTypeDefaultAllowed values and meaning
i18ni18n mapnoneThe text of the candidate in each language. Keys: name, alias, description.
is_explicit_invalidBooleanfalsetrue: this option makes the ballot invalid on purpose.
is_explicit_blankBooleanfalsetrue: this option is a blank vote.
is_disabledBooleanfalsetrue: the voting portal does not show the candidate, for example a withdrawn candidate.
is_category_listBooleanfalsetrue: this candidate is the header of the list with the same type. enable_checkable_lists of the contest sets if the voter can select the whole list.
invalid_vote_positionTextnoneFor an explicit invalid option: top or bottom of the contest.
is_write_inBooleanfalsetrue: this is a write-in field. The voter types a name.
sort_orderIntegernoneThe position of the candidate when the contest uses the custom candidate order.
urlsListnoneLinks of the candidate. See Candidate URLs.
subtypeTextnoneThe subtype of the candidate inside its type.

Candidate URLs​

Each object in urls:

FieldTypeRequiredMeaning
urlTextYesThe address.
kindTextNoThe kind of link.
titleTextNoThe title of the link.
is_imageBooleanYestrue: the voting portal uses this address as the image of the candidate.

If there is a problem​

ProblemAction
The import fails with invalid UUID or is not v4.Make sure that each id, tenant_id, election_event_id, election_id and keys_ceremony_id is a UUID.
The import fails with an error about a presentation.A field of presentation has a wrong type or a value that is not allowed. Correct it with the tables on this page.
A candidate is not on the ballot.Make sure that contest_id is the id of a contest in the file, and that presentation.is_disabled is not true.
The publication fails with Error parsing CountingAlgorithm.Set counting_algorithm of the contest to an allowed value.
The publication fails with an error about annotations.Make sure that each value in annotations is text.
