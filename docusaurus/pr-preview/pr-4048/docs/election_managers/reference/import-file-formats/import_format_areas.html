Area File

The area file is a text file with one row for each area. You make it yourself, for example in a spreadsheet. You import it in an election event, on the Areas tab, with Import. For the steps, see Import areas (alternative).

Each row creates one new area. The import does not change areas that already exist. Import the areas before the voters. The voter file refers to areas by name.

Fields​

The file has no header row. The six columns must be in this order. The table lists each column. The header names in the table come from the source format. The import does not read them.

ColumnHeader name (not read)RequiredAllowed valuesMeaningExample
1EMB_IDYesTextThe Name of the area. The voter file refers to this name.North
2CTRY_CODENoAnyNot used. The import ignores it. Leave it empty.
3EMB_CODENoAnyNot used. The import ignores it. Leave it empty.
4AREANAMENoTextThe Description of the area.North District
5isdeleteYes0The import flag. Only 0 imports the row. Any other value, or an empty cell, skips the row.0
6EARLY_VOTING_POLICYNoallow_early_voting or no_early_votingThe early voting policy of the area. Only allow_early_voting allows early voting. Any other value, or an empty cell, means no_early_voting.no_early_voting

Name​

  • The import uses column 1 as it is. It does not remove spaces around the name.
  • The import does not check that column 1 is not empty. A row with an empty column 1 creates an area with an empty name. Check each row before you import.
  • The import does not check for duplicate names. Each row creates a new area, even if the name exists. The voter import then chooses one of the areas with that name. The choice is not defined.
CAUTION: importing the areas file again

Importing the same file again creates the areas again. Check the Areas tab before you import the file a second time.

Contests​

An import links each new area to all the contests of the election event that exist at the time of the import. Remove the contests that do not belong to an area. See Rules.

Early voting​

The import does not check the voting channels of the election event. An area that gets allow_early_voting keeps it, even if the Early voting channel is off.

On the area form, the Allow Early Voting box is disabled while the Early voting channel is off.

Example file​

North,,,North District,0,no_early_voting
South,,,South District,0,allow_early_voting
Old Area,,,Old District,1,no_early_voting

The first row creates the area North. Early voting is not allowed in this area. The second row creates the area South. Early voting is allowed in this area. The third row is not imported, because column 5 is 1.

Rules​

RuleValue
Header rowDo not add one. The import reads every row as data. A header row has isdelete in column 5, so the import skips it. Do not rely on this.
ColumnsSix columns in each row.
SeparatorA comma. A field that contains a comma must be in double quotes.
Import flagColumn 5 must be exactly 0. A space or another character skips the row.
Early voting policyColumn 6 must be exactly allow_early_voting. Upper case or extra spaces give no_early_voting.
Integrity checkIf you type a SHA-256 value, the import compares it with the hash of the file. The comparison ignores upper and lower case. It does not ignore spaces.
No integrity checkIf the field is empty, the portal asks you to confirm. The import then runs without a check.
All or nothingThe import saves all areas and links in one transaction. If an error occurs, no area is saved.
PermissionThe user needs the Edit Area permission.
File sizeThe upload limit of your environment. The import has no row limit.

Remove a contest from an area​

  1. On the Areas tab, click the edit icon of the area.
  2. In Contests, remove the contests that do not belong to the area.
  3. Click Save.

The save replaces all contest links of the area with the contests that remain in the field.

What the import does​

  1. The portal uploads the file. The Import button is enabled after the upload ends.
  2. Type the SHA-256 value of the file in Integrity Check (SHA-256). This step is optional. If the field is empty and you click Import, the portal asks Import Without Integrity Check?. Click Yes, Import without Integrity Check to continue, or Go Back to stop.
  3. The server checks the hash, if you typed one. A mismatch stops the import.
  4. The server reads each row. It skips each row where column 5 is not 0. For each other row, it creates one area with a new ID. The early voting policy comes from column 6.
  5. The server links each new area to all the contests of the election event.
  6. The server saves all areas and links in one transaction. If one step fails, the server saves nothing.
  7. The portal shows Areas Imported Successfully and refreshes the list. The import does not send any message.

The area import does not start a task. There is no task log for it. The result shows in the portal only.
