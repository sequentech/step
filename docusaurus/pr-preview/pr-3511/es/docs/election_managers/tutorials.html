Una tarea en detalle: todas sus opciones, estados y errores.

📄️ System Navigation

The system's user interface (UI) is divided into four main areas, each serving a specific function:

📄️ Create Election

This tutorial guides you through the process of creating a new election event, setting up specific elections, and adding contests and candidates within the Sequent Admin Portal.

📄️ Active/Archive Elections

The Sequent Admin Portal allows you to manage the visibility of your electoral events by categorizing them as either Active or Archived.

📄️ Import/Export of Elections

The Sequent Admin Portal provides tools to export election data for backup or auditing and to import existing election configurations to quickly set up new events.

📄️ Configure Password Policy

Each election event has its own Keycloak realm and password policy.

📄️ Define Areas

Areas allow you to organize an election into specific geographic or logical divisions, such as wards or districts. This structure enables you to assign specific contests to relevant groups of voters.

📄️ Create Voters

Create voters one by one in the admin portal, protect secret voter fields and export the voters.

📄️ Import Voter List

Import the voter list of an election event from a CSV file: the columns, the formats and the checks.

📄️ Election Localization

The Sequent platform allows administrators to overwrite or customize any text appearing in the Admin Portal or the Voter Portal.

📄️ Key Ceremony

The Key Ceremony is a vital security procedure that ensures the integrity and secrecy of an election.

📄️ Initialization Report

The main path is in Publish and Manage the Voting Period. This page gives the details: when the report is necessary, what blocks it and how it unblocks the voting period.

📄️ Publish Election

Every time an administrator modifies data at the electoral event, election, contest, or candidate level, those changes must be published to become visible in the Voter Portal.

📄️ Scheduled Events

The main path to schedule the voting period is in Publish and Manage the Voting Period. This page gives all the types of scheduled events, their effect and the rules that apply when they run.

📄️ Start/Pause/Stop Election

The main path is in Publish and Manage the Voting Period. This page gives the status model of the voting channels, the rules for each menu item and the edge cases.

📄️ Voter Communication

Send messages to voters by email or SMS from the admin portal, with templates and per-voter variables.

📄️ Tally Ceremony

The main path is in Run the Tally Ceremony. This page gives the details: the statuses, the policies that block or permit a tally, the automatic tally, the resolution of ties, the recount and the…

📄️ Election Results

The main path is in Get the Results. This page gives the details: the sections of the results page, all the export formats and levels, and the publication on the results website.

📄️ Reports and Templates

To generate a report, you need to select the Election Event in the Admin Portal and add an entry for a specific report type.

📄️ Election Logs

The procedures Publish and Manage the Voting Period, Run the Tally Ceremony and Get the Results give the main path of an election.

📄️ Export Data

Export the voters of an election event to a CSV file, or include them in an election event archive, with or without the secret voter fields.

📄️ Create and set google meet credentials

Create Google Meet credentials and set them in the admin portal, so the platform can make video meeting links.

📄️ Adding User Attributes to Keycloak

The system supports adding additional user attributes that will appear as new fields in the user data.

📄️ Linking Multiple IdP Identities to a Single User via Custom Attribute

By default, Keycloak's identity brokering links an external Identity Provider (IdP) user to a Keycloak user on a 1-to-1 basis, usually by matching email or username.
