Tenant Backup File

The tenant backup file is a ZIP file with the configuration of a tenant. You make it with Backup in Settings > Backup / Restore. You use it with Restore on the same page. Do not make the file by hand.

Use the backup to keep a copy of the settings of the tenant. You can also copy the settings to another tenant. The backup does not contain election events, voters or votes.

CAUTION: tenant backup file

Keep the backup file in a protected location. The file contains the settings and the login configuration of the tenant. Anyone who has the file can read it.

You need the permission Read Tenant (tenant-read) to make the backup. You need the permission Edit Tenant (tenant-write) to restore it.

Files in the ZIP​

The admin portal downloads the file with the name tenant-config-<tenant ID>-export.zip. The ZIP has three files. <id> is the ID of the tenant.

FileContentUsed by the restore
tenant_configuration-<id>.csvThe settings of the tenant. One header row and one data row.Option Import Tenant Configurations
keycloak_admin-<id>.jsonThe login configuration of the tenant (the realm of the login service), in JSON.Option Import Keycloak Configurations. Only the display name and the texts.
export_permissions-<id>.csvThe roles and their permissions.Option Import Roles & Permissions Configurations

The restore finds a file by a part of its name: tenant_configuration, keycloak_admin and export_permissions. The restore skips the entries that start with . or __MACOSX/, and the folders. A ZIP file that you make again works if the three file names are the same.

Fields of tenant_configuration-<id>.csv​

The file has a header row and one data row. The restore reads the columns by position, not by name. The export writes each value as JSON. A text value has its own double quotes. In the CSV file, each value therefore has three double quotes on each side.

ColumnPositionRequiredAllowed values or formatMeaningUsed by the restoreExample
id0YesA UUIDThe ID of the tenant.No. The restore changes the tenant that you are signed in to."90505c8a-23a9-4cdf-a26b-4e19f6a097d5"
slug1YesTextThe short name of the tenant.No. The restore reads it but does not save it."example"
created_at2OptionalDate and time in ISO 8601When the tenant was made.Yes"2026-01-05T10:00:00+00:00"
updated_at3OptionalDate and time in ISO 8601When the tenant changed.Yes"2026-10-01T09:30:00+00:00"
labels4OptionalJSONExtra data.Yesnull
annotations5OptionalJSON objectThe look and feel of the tenant: logo_url and css.Yes{"logo_url":"https://example.com/logo.png","css":""}
is_active6Yestrue or falseShows if the tenant is active.Yestrue
voting_channels7OptionalJSON object, see belowThe voting channels of the tenant.Yes{"online":true,"kiosk":false}
settings8OptionalJSON object, see belowThe settings of the tenant.YesSee below.
test9OptionalA whole number or nullA flag for test tenants.No. See the note below.null

If is_active is missing or is not true or false, the restore stops with an error. See Messages and errors. The restore sets created_at and updated_at to the values of the file. If a date cannot be read, the restore saves an empty date.

Keys of voting_channels​

KeyTypeMeaning
onlinetrue or falseVoting on the internet. If the key is missing, the admin portal shows true.
kiosktrue or falseVoting in a kiosk. If the key is missing, the admin portal shows false.

The restore keeps any other key in this field. The admin portal of this version does not show them.

Keys of settings​

All keys are optional.

KeyTypeMeaning
language_confObjectThe languages. It has enabled_language_codes (a list of codes, for example ["en","es"]) and default_language_code (for example "en").
voting_countriesList of textThe countries where voting is blocked. See Country Blocking.
enroll_countriesList of textThe countries where enrollment is blocked. See Country Blocking.
help_linksList of objectsThe help links of the voting portal. Each object has url, title and optional i18n.
i18nObjectTexts of the tenant for each language.
sms, mailtrue or falseThe channels for messages. If the key is missing, the admin portal shows mail as true and sms as false.
schedules, schedulesIdsListScheduled events of the tenant.

Note on the column test​

The restore reads the field test from position 8, which is the column settings. It does not read position 9. The column test of the file is not used. The value of settings is not a whole number, so the restore saves an empty value (NULL) in the field test of the tenant. The export file is correct. The restore always clears the field test.

Fields of keycloak_admin-<id>.json​

The file is the full JSON of the realm of the login service for the tenant. The restore reads only two parts of it:

KeyTypeMeaning
displayNameTextThe display name of the realm. The restore sets it in the realm of the tenant.
localizationTextsObjectThe texts of the login pages for each language. The restore replaces the texts of the realm.

The restore ignores all other parts of the JSON: users, clients, flows, groups, roles and the settings of the realm. If a part is missing in the file, the restore does not change it.

Fields of export_permissions-<id>.csv​

A CSV file with a header row and two columns. The separator is a comma.

ColumnPositionRequiredFormatMeaningExample
role0YesTextThe name of a group of the realm. In the admin portal this is a role.Election Manager
permissions1YesNames of permissions, separated with |The permissions of the role.voter-create|voter-read|tenant-read

Example:

role,permissions
Election Manager,voter-create|voter-read|tenant-read
Auditor,voter-read|tenant-read

The export lists the groups of the realm that have realm roles. The order of the rows is not fixed.

For each row, the restore does this:

  1. If the realm has a group with the name in role, the restore makes the permissions of the group the same as the list. It adds the permissions that are missing. It removes the permissions that are not in the list. The restore ignores a permission name that does not exist in the realm.
  2. If the realm has no such group, the restore makes the group. It adds to the group the permissions of all rows read so far, not only the permissions of its own row.
CAUTION: permissions file of the tenant backup

The restore removes permissions from a role that exists. Check the file before you restore.

Rules​

RuleValue
File type.zip
CSV separatorComma. The encoding is UTF-8.
Multiple valuesIn permissions, separate the names with |.
File namesKeep the names of the three files.
TenantThe restore changes the tenant that you are signed in to. It does not use the tenant ID in the file.
SizeThe size is limited by the deployment setting for file uploads.

Restore options​

The Restore panel has three options:

  • Import Tenant Configurations
  • Import Keycloak Configurations
  • Import Roles & Permissions Configurations
NOTE: tenant backup restore options

In this version the Restore button works only if you select all three options. The task itself reads each option on its own. A file that does not have one of the three files gives no error for that option: the restore does nothing for it.

Example​

A complete ZIP file for a tenant with ID 90505c8a-23a9-4cdf-a26b-4e19f6a097d5:

tenant-config-90505c8a-23a9-4cdf-a26b-4e19f6a097d5-export.zip
  tenant_configuration-90505c8a-23a9-4cdf-a26b-4e19f6a097d5.csv
  keycloak_admin-90505c8a-23a9-4cdf-a26b-4e19f6a097d5.json
  export_permissions-90505c8a-23a9-4cdf-a26b-4e19f6a097d5.csv

Content of tenant_configuration-<id>.csv (the data row is on one line):

id,slug,created_at,updated_at,labels,annotations,is_active,voting_channels,settings,test
"""90505c8a-23a9-4cdf-a26b-4e19f6a097d5""","""example""","""2026-01-05T10:00:00+00:00""","""2026-10-01T09:30:00+00:00""",null,"{""logo_url"":""https://example.com/logo.png"",""css"":""""}",true,"{""online"":true,""kiosk"":false}","{""language_conf"":{""enabled_language_codes"":[""en"",""es""],""default_language_code"":""en""}}",null

What the restore does​

  1. The admin portal uploads the file and asks for the Integrity Check (SHA-256). If you type a hash, the task checks it. If you leave the field empty, the admin portal shows the dialog Import Without Integrity Check?. Select Yes, Import without Integrity Check to continue, or select Go Back to type the hash.
  2. The task Import Tenant Config starts. Look at the task widget or the Tasks tab.
  3. The task reads the realm of the tenant from the login service.
  4. For each selected option, the task reads the matching file in the ZIP. It then changes the tenant (database), the realm (display name and texts) or the roles (groups and permissions).
  5. The restore changes the existing tenant. It does not make a new tenant.

The task makes the changes in the login service one after the other. If the task fails in the middle, some changes remain.

If the database commit fails, the task still shows as completed. The tenant settings are not saved. The changes that the task made in the login service before the commit remain.

Messages and errors​

Each message in the task log starts with Error: . The task log shows only the first part of the error.

Message (task log)WhereMeaning and action
Import Tenant ConfigTask nameThe name of the task in the Tasks tab.
Error: Failed to verify the integrity: Hash of voters file: ... does not match with the input hash: ...Task logThe hash you typed is not the hash of the file. The text says "voters file", but it refers to this file.
Error: Failed to get zip entriesTask logThe file cannot be read as a ZIP file. The detail in the log is Zip archive error: ....
Error: Failed to upsert tenantTask logThe tenant file has a problem. The detail is Invalid header name: ... (a column name has a character that is not allowed) or Error deserializing is_active (the column is_active is not true or false).
Error: Failed to deserialize Keycloak realm configuration: ...Task logThe JSON file is not valid.
Error: Error obtaining realmTask logThe login service did not answer. Try again.
Error: Error reading roles and permissions config file: ...Task logThe roles file cannot be read. Check that it is a CSV file with the columns role and permissions.
Error: Role not found, Error: Permissions not foundTask logA row of the roles file does not have a value in role or in permissions.
Error: Error adding missing roles to group '...', Error: Error removing unnecessary roles from group '...'Task logThe login service refused the change of the permissions of an existing group.
Error: Error creating group '...' and assigning permissionsTask logThe login service refused to make the group.
Error: Error adding roles to new group '...'Task logThe login service made the group, but it refused the permissions of the group.
Error: Failed to upsert realm configuration in KeycloakTask logThe login service refused the display name or the texts of the realm. Try again.
