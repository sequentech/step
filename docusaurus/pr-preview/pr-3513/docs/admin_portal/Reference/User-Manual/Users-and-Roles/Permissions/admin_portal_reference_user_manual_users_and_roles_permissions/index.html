Permissions

A permission lets a user see a menu item, a tab or a button, or do an action. You give permissions to roles on the Roles tab, and roles to users on the Users tab. This page lists the permissions of version 9.0 with the label that the Roles tab shows.

How permissions work​

  • A user gets the permissions of all their roles.
  • A tab or a button that needs a permission does not show without it. The reference page of each screen gives the permissions of that screen.
  • Many tabs need two permissions: one to see the tab, for example View Election Event Keys, and one for the data, for example Admin Ceremony.
  • The View ... settings permissions of the Settings tabs exist, but version 9.0 does not use them. The Settings page needs View settings and Edit Tenant.
  • Some actions are sensitive. Even with the permission, the admin portal asks for your password again. See Before You Start.
  • Permission labels are a different function. They limit the elections that a user can see. See Permission Labels.

Change the permissions of a role​

  1. In the menu on the left, click Users and Roles.
  2. Click the Roles tab.
  3. Click the edit icon of the role.
  4. Select or clear Active for the permission.

Expected result: the message "Permission edited" shows. See Roles.
